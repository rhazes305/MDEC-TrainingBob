## Ciri-ciri

- 📅 **Main page**: Kalendar semasa dengan acara & aktiviti setiap hari
- 🔴 **Admin**: Urus pengguna, urus acara, laporan peratus aktiviti per unit
- 🟢 **Unit**: Input & urus aktiviti (nama, tujuan, pencapaian, status, justifikasi)
- 🔵 **Guest**: Lihat kalendar + klik hari untuk butiran acara

## Data

Data tersimpan dalam `localStorage` browser. Data dummy disediakan secara automatik.

## Cara Aktifkan GitHub Pages

1. Pergi ke **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / folder: **/ (root)**
4. Klik **Save**
5. URL: `https://rhazes305.github.io/MDEC-TrainingBob/Takwim-Politeknik-Web/`
